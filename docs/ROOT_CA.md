# Root CA

`root_ca.crt` is generated by `install.sh`, not stored in the repository. Copy it from the Docker host to every client and import it into the trusted Root CA store, or download it from `http://<HOST_IP>` — this works immediately on a brand-new client with no DNS/hosts entry and no certificate warning, since it's plain HTTP (see [Certificate Download Portal](CERTIFICATE_PORTAL.md#bootstrapping-without-any-dnshosts-entry-first) for why). Once hostnames resolve, `https://certificates.<HOSTNAME_FQDN>` serves the same content.

Windows PowerShell as Administrator:

```powershell
Import-Certificate -FilePath .\root_ca.crt -CertStoreLocation Cert:\LocalMachine\Root
```

Ubuntu or Debian:

```bash
sudo cp root_ca.crt /usr/local/share/ca-certificates/stepca-demo.crt
sudo update-ca-certificates
```

After `docker compose down -v`, a new CA is generated and must be imported again.
